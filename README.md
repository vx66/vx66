I'm **Xergno**. I like taking things apart, figuring out how they work, and making them do things they were never supposed to do.

I build small tools, homebrew software, web experiments, and games. I also spend an unreasonable amount of time with old computers, Japanese visual novels, obscure media, and unfinished ideas.

**DEAD SMILE** is my personal hacklab: a place to publish experiments, research, and whatever strange thing I'm working on next.
